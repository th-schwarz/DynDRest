= systemd Service Configuration

== Example Configuration

[source,console]
----
[Unit]
Description=DynDRest - A simple REST-service for dynamic DNS.
After=network.target
Requires=network.target

[Service]
User=dyndrest
Group=dyndrest
WorkingDirectory=/opt/dyndrest
ExecStart=/usr/bin/java -jar /opt/dyndrest/dyndrest.jar
ExecStop=/bin/kill -15 $MAINPID
SuccessExitStatus=143

[Install]
WantedBy=multi-user.target
----

====
Don't forget to customize user, group, the path to java and the path to the jar file!

The `WorkingDirectory` is important, because `dyndrest.yml` and the h2 database are expected in the working directory by default.
====
